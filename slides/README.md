# Slides: Parallel Model Merging

Five slides on why we need Git merging for MAPS files and Simulink models:
the problem and its impact, today's workflow, the workflow with merging,
time saved, and what comes next.

- **PowerPoint file:** [Parallel_Model_Merging.pptx](Parallel_Model_Merging.pptx).
  Click it, then **Download raw file** (or **View raw**) to save it.
- **Online version of the same deck:** https://claude.ai/artifact/BKRANbQay3A3K8AXXLCCJq
  It opens only for its owner's claude.ai account, unless it has been shared
  from the page's Share menu. It can also be exported from there as
  PowerPoint or PDF.

The time figures on the "Time saved" slide are rough estimates for a typical
change: a few model blocks and 10 to 40 MAPS values. The monthly figure
assumes 5 engineers with 4 overlapping deliveries each per month. Replace
them with the team's real numbers.
